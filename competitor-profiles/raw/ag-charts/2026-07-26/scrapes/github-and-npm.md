# AG Charts repository and package notes

**Retrieved**: 2026-07-26

## GitHub

**Source**: https://github.com/ag-grid/ag-charts

- Public monorepo with Community, Enterprise, core, types, React, Angular, Vue,
  locale, website, and server-side packages.
- Snapshot: 474 stars, 43 forks, 33,975 commits, 3 open issues.
- Community is MIT licensed; Enterprise is commercially licensed.
- Repository copy describes the engine as canvas-based, dependency-free, and
  framework-portable.
- AG Charts is the engine behind AG Grid Integrated Charts.

The raw GitHub popularity is modest beside the package adoption. The repository
also contains Enterprise source, so source visibility does not imply MIT rights
for the entire product.

## npm

**Source**: https://www.npmjs.com/package/ag-charts-community

- Snapshot version: `14.0.2`.
- Published: 2026-07-22.
- Weekly downloads shown on 2026-07-26: 1,626,168.
- License: MIT.

The download count is a strong distribution signal, but it should not be read
as 1.6 million standalone applications. AG Grid integration, CI, lockfile
updates, and transitive workflows can contribute.
