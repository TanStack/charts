# AG Charts homepage notes

**Retrieved**: 2026-07-26  
**Source**: https://www.ag-grid.com/charts/javascript-charts/

## Positioning

- “The professional choice for developers building enterprise applications.”
- Fully featured, highly customisable, canvas-based JavaScript charting.
- Promotes high performance, no runtime dependencies, TypeScript, and support
  for JavaScript, React, Angular, and Vue.
- Claims 30+ chart types across common cartesian, polar, hierarchy, financial,
  map, gauge, and flow visualisations.
- AG Charts powers AG Grid Integrated Charts.

## Product framing

- Community covers the common application-chart path.
- Enterprise adds specialised series and end-user analysis features, including
  Financial Charts, maps, gauges, zoom, crosshairs, navigator, annotations, and
  context menus.
- Primary call to action is to start with Community and trial or buy Enterprise.

## Technical claims

- Browser rendering uses HTML Canvas.
- The library has no third-party runtime dependencies.
- Large-data handling uses the M4 aggregation algorithm.
- The quick-start model is `AgCharts.create(options)` with `data` plus
  `series: [{ type, xKey, yKey }]`.

## Interpretation

AG Charts sells breadth and completeness rather than a low-level visual
grammar. The ideal buyer wants a production-ready chart component with a large
catalog and minimal need to assemble primitives.
