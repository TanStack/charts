# AG Charts product-history notes

**Retrieved**: 2026-07-26  
**Sources**:

- https://blog.ag-grid.com/introducing-ag-charts/
- https://blog.ag-grid.com/introducing-ag-charts-enterprise/

## Timeline

- 2019: built by the AG Grid team to power Integrated Charts.
- 2020: extracted and released as a free, standalone charting library after
  users asked for direct API control and charts independent of the grid.
- 2023: Enterprise launched after Community reached a reported 300,000 npm
  downloads per month.
- 2025–2026: expanded aggressively into large data, live updates, financial
  workflows, hierarchy, server rendering, async data, and richer interaction.

## Original goals

- Preserve the integrated-chart engine while giving developers direct control.
- Keep the API approachable for developers new to charting.
- Use the same options object across JavaScript and framework wrappers.
- Deliver a modern, lightweight, fast Canvas implementation without external
  dependencies.

## Current goals — inference from positioning and releases

- Become the default chart layer for enterprise web applications, especially
  applications already using AG Grid.
- Cover common and specialised application charts through a broad first-party
  catalog.
- Monetise advanced interaction, specialised visualisations, and support.
- Extend from components into a full embedded-analytics suite through AG
  Studio.
