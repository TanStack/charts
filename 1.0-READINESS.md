# TanStack Charts 1.0 readiness

The goal is a stable public API backed by verified published packages. This file
tracks the work and its evidence. An unchecked gate blocks readiness. Publishing
1.0 is a separate release decision after these gates pass.

## Required gates

- [x] Review and integrate portable inferred declarations, issue #156 / PR #157.
      Emit declarations from installed tarballs and compile them downstream.
- [ ] Review and integrate map and polar states, issue #126 / PR #158.
      Verify source ownership, transitions, restoration, renderer behavior,
      and the measured optional bundle costs.
- [ ] Review and integrate adapter lifecycle coverage, PR #155.
      Verify updates, duplicate mounts, teardown, SSR, and hydration.
- [ ] Resolve state ownership for composed datum groups, issue #135.
      One group must own its paint and animation without applying the same
      opacity to every descendant. Cover nested state overrides.
- [ ] Resolve focus styling for tick labels and point-less marks, issue #134.
      Pointer movement must not require rebuilding the chart definition or
      adding hit-test points to decorative geometry.
- [ ] Resolve legend emphasis, issue #127.
      Hover and keyboard emphasis must preserve pinned focus and avoid
      unintended tooltips, crosshairs, and focus-filtered geometry.
- [ ] Publish the 1.0 compatibility contract and support boundaries.
      Cover public types, extension protocols, framework and runtime support,
      deprecations, renderer differences, and explicitly experimental features.
- [ ] Verify the complete candidate with unit, type, documentation, packaged
      consumer, framework, native, and browser conformance checks.
      Include keyboard interaction, reduced motion, SSR/hydration, and export.
- [ ] Verify size and performance against equivalent production builds.
      Record per-entry costs and representative scene, pointer, animation,
      update, and teardown measurements. Keep expensive release checks outside
      routine PR CI.
- [ ] Verify release automation and the versioned release candidate artifacts.
      Check coordinated versions, peer ranges, migrations, package contents,
      installability, and provenance before declaring readiness.

## Latest legend evidence

Interactive color legends now have opt-in `hover: 'series'` for pointer and
keyboard emphasis. The host keeps inline-state matching separate from real
interaction focus. Series lookup stays in the optional legend module. Unit
tests preserve pinned focus, unchanged tooltip text, and real tick-label focus.
SVG and motion browser fixtures pass in Chromium, Firefox, and WebKit, including
unfocused hover, keyboard emphasis, restoration, and host teardown.

The full unit run passes 2,191 tests across 301 files. TypeScript and the
documentation contract pass after making host control contexts generic in the
chart datum and axis values. The new legend handlers allocate only when hover
is enabled for a visible item. Final package validation of this new protocol
is recorded below.

Package verification of the new state-focus protocol now passes, including
portable consumer declarations, packed runtime exports, seven framework
adapters, unified artifacts, bare React Native Metro, and Expo Metro. A Canvas
unit regression passes for pointer and keyboard opacity paint and null-focus
restoration. Update regressions pass for new datum ownership, disabling hover,
hiding the emphasized series, and removing the legend entirely.

Canvas pixel checks now pass in Chromium, Firefox, and WebKit for unfocused
hover restoration, pinned-focus restoration, keyboard emphasis, unchanged
tooltip text, and host teardown, with no page errors. The fixture uses `z` as
the dot's semantic series and default color channel. A failing visibility
regression additionally exposed missing color-series ownership metadata on
these dots. That metadata is now retained; independent per-point colors remain
separate from semantic series.

This gate is not complete: reduced motion, interrupted data transitions, and
final verification of the full combined candidate remain. The unchanged size check
fails. Against locked baselines, static line SVG adds 46 gzip bytes, the DOM
host adds 279, and the React line consumer adds 307. These costs are not approved.

The latest full unit run, including Canvas and update regressions and the dot
visibility correction, passes 2,195 tests across 301 files. TypeScript passes.
The package run above predates the dot visibility metadata correction, so the
final release artifact audit must still verify that last change.
